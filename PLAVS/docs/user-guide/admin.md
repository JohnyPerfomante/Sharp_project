# Інструкція адміністратора

1. У Production створіть першого адміністратора командою `--bootstrap-admin` з належними змінними середовища. Development має окремі демонстраційні облікові записи.
2. У «Користувачах» створіть облікові записи викладачів і студентів. Пароль має щонайменше 12 символів, великі й малі латинські літери, цифру та спеціальний символ. Новий пароль при редагуванні необов'язковий.
3. Блокування, зміна ролі або скидання пароля відкликають стару сесію. Неможливо заблокувати себе, зняти власну адміністративну роль або усунути останнього активного адміністратора.
4. Створіть групу, відкрийте «Склад групи» й позначте потрібних студентів. Створіть дисципліну та через «Призначення» додайте викладачів і групи. Без призначень викладач не має доступу до матеріалів, а студент не бачить відповідних тестів.
5. «Огляд системи» показує кількість користувачів, матеріалів і відповідей із PostgreSQL. «Журнал дій» відображає критичні операції; «Стан системи» — доступність БД та локальної моделі.
6. Для налаштування ONNX використовуйте pinned downloader; після встановлення потрібен перезапуск API. Великі модельні файли не додавайте до Git.
7. Адміністратор має узагальнені звіти та системні налаштування. Ця роль сама по собі не надає можливості змінювати академічні оцінки або читати тексти відповідей через викладацькі маршрути.
8. Регулярно виконуйте резервування та перевірку відновлення. Захищайте `.env`, PostgreSQL, резервні копії та Data Protection keys засобами середовища розгортання.
