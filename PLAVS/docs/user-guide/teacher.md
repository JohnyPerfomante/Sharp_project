# Інструкція викладача

1. Увійдіть своїм обліковим записом. «Мої дисципліни» показує лише призначені дисципліни. Щоб працювати з групою, адміністратор має пов'язати її з дисципліною.
2. У «Банку питань» оберіть «Створити питання». Задайте дисципліну, тему, питання, основний еталон і ключові поняття. Для кожного поняття задайте додатну вагу; синоніми та потрібні словоформи розділяйте `;`. Для нового питання доступні поля трьох варіацій.
3. На сторінці питання можна додавати додаткові еталони, редагувати основний, переглядати історію, керувати поняттями та архівувати питання. Редагування створює попередню версію. За конфлікту оновіть сторінку, щоб не перезаписати чужу зміну.
4. У «Лінгвістичних варіаціях» перевірте правильність кожного формулювання й натисніть «Затвердити». Pending, Rejected та Inactive не беруть участі в новому аналізі. Редагування затвердженої варіації потребує повторного погодження.
5. У «Конструкторі тестів» додайте назву, інструкцію, дисципліну, групи, питання й бали. Установіть тривалість та за потреби початок/кінець доступу. Позначте «Опублікувати тест». Дати відображаються в часовому поясі браузера, на сервері зберігаються в UTC.
6. Після першої спроби склад тесту зафіксований. Щоб змінити матеріали для нового оцінювання, створіть інший тест. Зміна поточного банку не змінює знімки вже розпочатих спроб.
7. У «Відповідях студентів» доступні всі надіслані відповіді вашого scope. «Ручна перевірка» початково показує NeedsReview; фільтр дозволяє знайти також помилки аналізу або вже перевірені відповіді.
8. Сторінка перевірки показує текст студента, L/M/K/S, поняття, пояснення, попередження й вибраний еталон зі знімка. За відсутності моделі S не визначається. Після виправлення технічної проблеми оберіть «Повторити аналіз».
9. Збережіть рішення з коментарем: зарахувати — 100%, відхилити — 0%, частково — обраний відсоток, додаткова перевірка — без бала. Остаточні рішення зберігаються в історії. Повторний автоматичний аналіз не замінює Reviewed-рішення.
10. Для повністю зарахованої відповіді можна створити кандидата варіації. Після цього його треба **окремо затвердити** в банку; студентський текст не стає правильним еталоном автоматично.
11. На картці тесту «Відкрити результати» дозволяє студентам бачити власні бали й коментарі. Еталони, поняття та чужі відповіді через студентський API не відкриваються.
12. «Статистика та звіти» фільтруються за дисципліною, групою, тестом і датами. CSV/XLSX містять узагальнені показники. «Налаштування аналізу» створює нову версію ваг і порогів лише для майбутніх спроб.
